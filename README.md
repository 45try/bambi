# BambiFix - Beauty Services Platform

A website for BambiFix, Uganda's leading beauty services platform that connects clients with beauty professionals in Kyebando.

## Features

- Responsive design for all devices
- Interactive navigation with hamburger menu
- Hero section with download buttons for the app
- Service showcase with animated marquee gallery
- Multiple pages: Home, About, Services, and Contact
- Beautiful orange-themed design
- Smooth scrolling navigation

## Pages

- **index.html** - Homepage with services overview
- **about.html** - Company information and testimonials
- **services.html** - Beauty services offered
- **contact.html** - Contact form and information

## Technologies

- HTML5
- CSS3 with responsive design
- Vanilla JavaScript
